# Dependencies & Technical Stack

## Frontend Dependencies

### Core Framework
- **React 18**: Modern React with concurrent features and improved performance
- **TypeScript**: Type-safe development with compile-time error prevention
- **Vite**: Fast build tool and development server with hot module replacement

### Styling & UI
- **TailwindCSS**: Utility-first CSS framework for rapid UI development
- **Radix UI**: Accessible, unstyled UI primitives for building design systems
- **CSS-in-JS**: Component-scoped styling with modern CSS features

### State Management
- **Zustand**: Lightweight state management with minimal boilerplate
- **React Hooks**: Built-in React state management and lifecycle hooks

### Game Development
- **HTML5 Canvas API**: Custom 2D game engine built on native web technologies
- **Custom Algorithms**: Shape matching and rune recognition algorithms
- **Game Loop**: Custom 60fps game loop implementation

### Utilities
- **Date-fns**: Modern date utility library for date manipulation
- **Type-safe APIs**: Custom type definitions for game data and APIs
